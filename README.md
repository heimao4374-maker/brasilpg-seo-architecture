# BrasilPG SEO Architecture

This repository contains a static front-end prototype for a Brazilian gaming/PG SEO platform based on the provided architecture.

## Included pages
- Homepage
- Slots, Crash, Roleta and Cartas landing pages
- Safety, Beginner, Payment and Strategy guide pages
- Blog landing page and article template
- FAQ, Support and About pages
- SEO files: robots.txt and sitemap.xml

## Run locally
Open `index.html` directly or serve locally with any static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
